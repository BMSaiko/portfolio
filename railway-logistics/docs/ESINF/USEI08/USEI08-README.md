# USEI08 - 2D Range Query for Stations

## Overview

This user story implements efficient 2D spatial range queries using a KD-tree data structure. The system allows planners to find all railway stations within a specified latitude/longitude rectangle, with optional filtering by station attributes (isCity, isMainStation, country).
