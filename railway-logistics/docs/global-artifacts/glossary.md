# Glossary

| ***TEA*** (EN)                       | ***Description*** (EN)                                                                                                                                                                       |
|:-------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Allocation**                       | Assignment of specific boxes and quantities to fulfill order line requirements.                                                                                                              |
| **Audit log**                        | Recorded history of inspection actions and decisions for returned or quarantined goods.                                                                                                      |
| **Bay**                              | Storage compartment within a warehouse aisle, used to hold a limited number of boxes.                                                                                                        |
| **Board**                            | A component that implements a console-based board. It provides all the functionalities for presenting data on a board, such as temperature, humidity, and the state of tracks, among others. |
| **Bogies**                           | Comprises two or more wheelsets (two wheels on an axle), in a frame, attached under a vehicle by a pivot. Bogies take various forms in various modes of transport.                           |
| **Box**                              | The smallest storage unit, identified by a unique boxId and containing a quantity of a specific SKU, possibly with an expiry date.                                                           |
| **Boxcar**                           | Enclosed freight wagon used for transporting general goods protected from weather.                                                                                                           |
| **Bridges**                          | Engineering structures that allow *Rail Line* to cross obstacles such as rivers or valleys, forming part of the railway infrastructure.                                                      |
| **Centrality**                       | A measure of a station's importance in the network, calculated using metrics like betweenness, harmonic closeness, and strength.                                                             |
| **Circulation lines**                | Tracks within a *Terminal* that allow wagons to move between parking lines and unloading docks.                                                                                              |
| **Conceptual data model**            | Abstract representation of system entities and their relationships, used to describe domain structure before implementation.                                                                 |
| **Container**                        | Standardized freight unit used to transport goods efficiently between trains, trucks, or ships in intermodal transport.                                                                      |
| **Crossing**                         | Operation where trains traveling in opposite directions pass each other on single-track lines.                                                                                               |
| **Data dictionary**                  | Centralized reference describing all data elements, their definitions, and relationships in the database.                                                                                    |
| **Dispatch operation**               | Process of removing stock from warehouse bays following FEFO/FIFO rules to fulfill orders or transport requirements.                                                                         |
| **Double-track**                     | Rail line with two parallel tracks, allowing trains to pass without speed reduction or special facilities.                                                                                   |
| **Electrified line segment**         | Rail line section equipped with electrical power supply, allowing operation of electric locomotives.                                                                                         |
| **Facility**                         | A building or a place. Can be a warehouse, station, freight yard, terminal.                                                                                                                  |
| **FEFO (First-Expired-First-Out)**   | Inventory management rule ensuring products with the earliest expiry date are dispatched first.                                                                                              |
| **Flatcar**                          | Open freight wagon designed to carry containers, vehicles, or machinery.                                                                                                                     |
| **Freight**                          | The collection of wagons forming a trainload of goods to be transported from one station to another.                                                                                         |
| **Freight Manager**                  | User responsible for planning freight transport operations and dispatching trains.                                                                                                           |
| **Freight Yard**                     | Area dedicated to assembling, sorting, loading, and unloading freight trains.                                                                                                                |
| **Fuel capacity**                    | Maximum volume of fuel a diesel *Locomotive* can store, determining its operational range.                                                                                                   |
| **Gauge**                            | Distance between the inner sides of the two rails, determining track compatibility and rolling stock types.                                                                                  |
| **Hopper car**                       | Freight wagon designed to transport bulk materials like coal, grains, or minerals.                                                                                                           |
| **HubScore**                         | A composite value used to rank the importance of stations, derived from normalized betweenness, closeness, and strength metrics.                                                             |
| **Intermodal Terminals**             | Specialized facilities where containers are transferred between different modes of transport (e.g., train to truck).                                                                         |
| **Intermodal Transport**             | Combined use of different transport modes (rail, road, sea) for door-to-door logistics operations.                                                                                           |
| **Itinerary**                        | Ordered travel plan defining the stations and paths a freight train will follow between origin and destination.                                                                              |
| **Latitude**                         | The angular distance of a place north or south of the earth's equator, usually expressed in degrees and minutes.                                                                             |
| **Light Sign**                       | A signaling device on a track with states: Green, Red, Yellow, or Red Blinking.                                                                                                              |
| **Line Segment**                     | Portion of a *Rail Line* defined by its *Track* configuration and electrification status.                                                                                                    |
| **Loading and unloading operations** | Activities of transferring cargo between trains, warehouses, and other logistics nodes.                                                                                                      |
| **Locomotive**                       | Self-propelled engine providing traction to move freight wagons along railway lines.                                                                                                         |
| **Locomotive type**                  | Classification of *Locomotive* propulsion system based on its power.                                                                                                                         |
| **Longitude**                        | The angular distance of a place east or west of the Greenwich meridian.                                                                                                                      |
| **Make**                             | Manufacturer or brand of a *Locomotive* or rolling stock vehicle.                                                                                                                            |
| **Minimal Backbone**                 | Minimal track length connection between all stations in a given rail network.                                                                                                                |
| **Model**                            | Specific type or design of a *Locomotive* or wagon produced by a manufacturer.                                                                                                               |
| **MVP (Minimum Viable Product)**     | Simplest functional version of the project that demonstrates core features and validates feasibility.                                                                                        |
| **Order**                            | Request for goods to be fulfilled, characterized by an order ID, due date, and priority level.                                                                                               |
| **Order line**                       | Individual item within an order, specifying a SKU and requested quantity.                                                                                                                    |
| **Parking lines**                    | Sidings within a *Terminal* where wagons are temporarily held before further movement or processing.                                                                                         |
| **Path**                             | Sequence of stations a train passes through between departure and arrival points.                                                                                                            |
| **Payload**                          | Maximum weight of cargo a wagon can carry.                                                                                                                                                   |
| **Picker**                           | Warehouse worker responsible for collecting goods from storage locations according to picking plans.                                                                                         |
| **Picking**                          | Warehouse operation of collecting products from storage locations according to a picking plan.                                                                                               |
| **Picking plan**                     | Organized list of products and locations to be collected by warehouse pickers to fulfill orders.                                                                                             |
| **Quality Operator**                 | User responsible for inspecting returned or quarantined goods and determining their final status.                                                                                            |
| **Quarantine**                       | Temporary holding status for returned or suspect goods requiring inspection before restocking or disposal.                                                                                   |
| **Rain Tracks**                      | Rail tracks exposed to outdoor conditions, typically part of open-air railway infrastructure.                                                                                                |
| **Rail Line**                        | Continuous railway connection composed of one or more line segments linking two endpoints.                                                                                                   |
| **Rail network**                     | A system of interconnected tracks, stations, and infrastructure that enables the movement of trains.                                                                                         |
| **Railway Infrastructure**           | Physical assets of the railway system, including tracks, stations, terminals, bridges, and tunnels.                                                                                          |
| **Refrigerated car**                 | Specialized freight wagon equipped with cooling systems for transporting perishable goods.                                                                                                   |
| **Relational model**                 | Logical data structure representing information as related tables in a database system.                                                                                                      |
| **Relocation operation**             | Process of moving boxes from one warehouse location to another while maintaining inventory positioning.                                                                                      |
| **Repository**                       | Centralized GitHub storage area for the team’s project code and documentation.                                                                                                               |
| **Return**                           | Product sent back to the warehouse, requiring inspection and decision on restocking or disposal.                                                                                             |
| **Rolling Stock**                    | All railway vehicles operating on tracks, including *Locomotive* and *Freight Wagons*.                                                                                                       |
| **Route**                            | Defined path or collection of paths a train follows to transport freight between endpoints.                                                                                                  |
| **Scheduler / Planner**              | User responsible for planning and optimizing train routes, timetables, and terminal operations.                                                                                              |
| **Scheduling and dispatching**       | Coordination of train movements to maximize efficiency and avoid delays.                                                                                                                     |
| **Scrum Board**                      | Agile project management tool displaying workflow states such as Backlog, To-Do, and Done.                                                                                                   |
| **Sensor**                           | A device which detects or measures a physical property and records or responds to it.                                                                                                        |
| **Side Track (Siding)**              | Auxiliary track allowing trains to pass or park while mainline traffic continues.                                                                                                            |
| **Signaling systems**                | Electronic and mechanical systems that ensure safe and coordinated train operations.                                                                                                         |
| **Single-track**                     | Rail line with one track, requiring trains to cross at stations or sidings.                                                                                                                  |
| **SKU (Stock Keeping Unit)**         | Unique product identifier used for inventory tracking and warehouse operations.                                                                                                              |
| **Station**                          | Facility where trains stop for loading, unloading, or crossing.                                                                                                                              |
| **Station Master**                   | Person responsible for managing the operations and traffic at a station.                                                                                                                     |
| **Station Storage Manager**          | User responsible for managing warehouse and inventory operations at a station.                                                                                                               |
| **Tank car**                         | Freight wagon designed to transport liquids or gases safely.                                                                                                                                 |
| **Task**                             | Defined piece of work within a sprint or operational process.                                                                                                                                |
| **Tare**                             | Empty weight of a wagon or container, excluding its cargo payload.                                                                                                                           |
| **Terminal**                         | Logistics facility for loading, unloading, and dispatching freight.                                                                                                                          |
| **Terminal Operator**                | User responsible for handling loading and unloading operations within a terminal.                                                                                                            |
| **Timezone**                         | An area which observes a uniform standard time.                                                                                                                                              |
| **Timezone Group**                   | A group of timezones.                                                                                                                                                                        |
| **Track**                            | Structure composed of two parallel steel rails where the train travels.                                                                                                                      |
| **Traffic Dispatcher**               | User responsible for coordinating train movements and calculating travel times.                                                                                                              |
| **Train**                            | A series of connected wagons moved by a locomotive.                                                                                                                                          |
| **Train Driver**                     | Operator of a locomotive, responsible for driving and safety.                                                                                                                                |
| **Train Operator**                   | Company owning and managing locomotives and wagons.                                                                                                                                          |
| **Trolley**                          | Cart used by pickers to transport collected items.                                                                                                                                           |
| **Tunnels**                          | Underground or covered passages allowing railway lines to pass through obstacles.                                                                                                            |
| **UI**                               | User interface. Console-based interface for program interaction.                                                                                                                             |
| **Unloading docks**                  | Access areas between tracks and warehouses for cargo transfer.                                                                                                                               |
| **Upgrade Plan**                     | An order of stations to schedule upgrades in a rail network.                                                                                                                                 |
| **Volume capacity**                  | Maximum volume of goods a wagon can hold.                                                                                                                                                    |
| **Wagon / Freight car**              | Rail vehicle designed to carry cargo.                                                                                                                                                        |
| **Warehouse**                        | Storage facility near stations or terminals for managing goods flow.                                                                                                                         |
| **Warehousing**                      | Process of storing, organizing, and managing goods within a warehouse.                                                                                                                       |
| **Year of entry into service**       | The year a locomotive or wagon was first introduced into operation.                                                                                                                          |
