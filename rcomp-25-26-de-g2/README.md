# RCOMP 2025/26 — Campus network

🇬🇧 English · [🇵🇹 Português](README.pt.md)

Computer Networks (RCOMP), ISEP 2025/26 — Group project (3 members).

## What it does
Structured cabling and network design for a multi-building campus, split in three sprints: per-member schematics, cabling plans and Packet Tracer simulations (`.pkt`) in `doc/`.

## Stack
Cisco Packet Tracer · Networking

## Notes
Design of the network infrastructure (UTP/fibre cabling, VLANs, routing) with documentation per sprint.
Build outputs, IDE folders and jars were left out.
