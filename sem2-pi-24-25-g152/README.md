# LEI 2nd semester — Railway game

🇬🇧 English · [🇵🇹 Português](README.pt.md)

Integrative Project, LEI 2nd semester (ISEP, 2024/25) — Group project (5 members).

## What it does
Java application where the player builds a railway network: cities, industries, stations, lines, locomotives and trains, cargo generation, maintenance, financial results and save games. Includes MATCP (Jupyter) and MDISC components and full per-user-story documentation in `docs/`.

## Stack
Java · Maven · Jupyter (MATCP) · UML

## Notes
Run `mvn compile exec:java` (main class `pt.ipp.isep.dei.Main`).
Build outputs, IDE folders and jars were left out.
