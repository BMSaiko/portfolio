# LEI 3rd semester — Railway stations and warehouses

🇬🇧 English · [🇵🇹 Português](README.pt.md)

Integrative Project, LEI 3rd semester (ISEP, 2025/26) — Group project (5 members).

## What it does
Railway logistics: `stationMngt` and `warehouseMngt` Java applications (traffic, train scheduling, travel times, freight, warehouse movements) backed by Oracle, with SQL scripts per sprint (`sql-scripts/`) and Scrum reports (`scrum/`).

## Stack
Java · Oracle SQL · Scrum

## Notes
Needs a local Oracle database; connection settings in the Java services and `config.txt` files are local dev defaults.
Build outputs, IDE folders and jars were left out.
