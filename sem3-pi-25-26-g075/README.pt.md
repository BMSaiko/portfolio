# LEI 3rd semester — Railway stations and warehouses

[🇬🇧 English](README.md) · 🇵🇹 Português

Projeto Integrador do 3.º semestre da LEI (ISEP, 2025/26) — Projeto de grupo (5 elementos).

## O que faz
Logística ferroviária: aplicações Java `stationMngt` e `warehouseMngt` (tráfego, agendamento de comboios, tempos de viagem, carga, movimentos de armazém) com Oracle, scripts SQL por sprint (`sql-scripts/`) e relatórios Scrum (`scrum/`).

## Stack
Java · Oracle SQL · Scrum

## Notas
Requer uma base de dados Oracle local; as ligações nos serviços Java e nos `config.txt` são predefinições locais de desenvolvimento.
Pastas de build, de IDE e jars ficaram de fora.
