# LEI 4th semester — AISafe flight control

🇬🇧 English · [🇵🇹 Português](README.pt.md)

Integrative Project, LEI 4th semester (ISEP, 2025/26) — Group project (5 members).

## What it does
Air-traffic/flight-control platform (AIControl/AISafe): domain-driven Java back office and company console apps with persistence, a logging server and a flight-control server, plus shared-memory/process simulation in C (`scomp/`), language-processing work (`lprog/`) and extensive planning docs (`docs/`).

## Stack
Java · EAPLI · Maven · C · PlantUML

## Notes
Build with `mvn clean install` in `aisafe-flight-control/`. One test file with a very long path (`InsertWeatherDataInFlightPlanUiAcceptanceTest.java`) could not be checked out on Windows and is not included.
Build outputs, IDE folders and jars were left out.
