# LEI 4th semester — AISafe flight control

[🇬🇧 English](README.md) · 🇵🇹 Português

Projeto Integrador do 4.º semestre da LEI (ISEP, 2025/26) — Projeto de grupo (5 elementos).

## O que faz
Plataforma de controlo de tráfego/voos (AIControl/AISafe): aplicações de consola Java orientadas ao domínio (back office e empresa) com persistência, servidor de logging e servidor de controlo de voo, simulação com processos/memória partilhada em C (`scomp/`), trabalho de processamento de linguagens (`lprog/`) e documentação extensa em `docs/`.

## Stack
Java · EAPLI · Maven · C · PlantUML

## Notas
Compilar com `mvn clean install` em `aisafe-flight-control/`. Um ficheiro de teste com caminho muito longo (`InsertWeatherDataInFlightPlanUiAcceptanceTest.java`) não pôde ser extraído no Windows e não está incluído.
Pastas de build, de IDE e jars ficaram de fora.
