# Glossary – Domain Model (AISafe)

**This glossary defines the key domain concepts used in the AISafe system, ensuring a consistent ubiquitous language across the project.**

---

## Aggregates & Entities

| **Term (EN)** | **Termo (PT)** | **Description (EN)** | **Descrição (PT)** |
|:---|:---|:---|:---|
| **User** | **Utilizador** | Aggregate root representing a system user uniquely identified by email, with authentication and authorization capabilities. | Agregado raiz que representa um utilizador do sistema identificado unicamente pelo email, com capacidades de autenticação e autorização. |
| **User: name** | **Utilizador: nome** | The user's full name. Value object {@link UserName}. | Nome completo do utilizador. Objeto de valor {@link UserName}. |
| **User: phoneNumber** | **Utilizador: telefone** | The user's phone number. Value object {@link PhoneNumber}. | Número de telefone do utilizador. Objeto de valor {@link PhoneNumber}. |
| **User: passwordHash** | **Utilizador: hash da palavra-passe** | BCrypt-hashed password. Minimum 8 characters, must contain at least one digit and one uppercase letter. | Palavra-passe hasheada com BCrypt. Mínimo 8 caracteres, deve conter pelo menos um dígito e uma letra maiúscula. |
| **User: status** | **Utilizador: estado** | Indicates whether the user account is active or inactive. Inactive users cannot access the system. | Indica se a conta do utilizador está ativa ou inativa. Utilizadores inativos não podem aceder ao sistema. |
| **User: securityClearanceExpiry** | **Utilizador: expiração da autorização de segurança** | The date on which the user's security clearance expires. After this date the user loses system access until the clearance is renewed. | Data em que a autorização de segurança do utilizador expira. Após esta data o utilizador perde o acesso até renovação. |
| **User: skillsAssessmentDate** | **Utilizador: data de avaliação de competências** | The date of the user's last skills assessment. Must be renewed every 5 years as required by regulation. | Data da última avaliação de competências do utilizador. Deve ser renovada a cada 5 anos conforme exigido pela regulamentação. |
| **User: roles** | **Utilizador: papéis** | The set of roles assigned to this user. A user may hold one or more roles simultaneously. | Conjunto de papéis atribuídos a este utilizador. Um utilizador pode ter um ou mais papéis simultaneamente. |
| **Role** | **Papél** | Value object (enum) defining the permissions and responsibilities assigned to a user. A user may hold one or more roles. | Objeto de valor (enum) que define as permissões e responsabilidades atribuídas a um utilizador. Um utilizador pode ter um ou más papéis. |
| **Role Type** | **Tipo de Papél** | Enumeration of all possible roles: `ADMIN`, `BACKOFFICE_OPERATOR`, `COLLABORATOR`, `AIR_TRANSPORT_COMPANY_COLLABORATOR`, `PILOT`, `FLIGHT_CONTROL_OPERATOR`, `WEATHER_PERSON`. | Enumeração de todos os papéis possíveis no sistema. O papel `ATCC` foi removido; foram adicionados `COLLABORATOR` e `AIR_TRANSPORT_COMPANY_COLLABORATOR` para distinguir colaboradores genéricos dos associados a uma empresa de transporte aéreo. |
| **Admin** | **Administrador** | A user responsible for managing users and system configuration. | Utilizador responsável pela gestão de utilizadores e configuração do sistema. |
| **Backoffice Operator** | **Operador de Backoffice** | A user responsible for configuring core domain data such as companies, airports, and aircraft models. | Utilizador responsável pela configuração dos dados principais do domínio como empresas, aeroportos e modelos de aeronaves. |
| **Collaborator** | **Colaborador** | A person employed by an air transport company or assigned to an air control area, associated with a system user account. A customer may be an air transport company or an air control area. | Pessoa empregada por uma empresa de transporte aéreo ou afet a uma área de controlo aéreo, associada a uma conta de utilizador do sistema. |
| **Collaborator: position** | **Colaborador: cargo** | The collaborator's job title or role within their employing organization (e.g., dispatcher, captain, first officer). | Cargo ou função do colaborador na organização empregadora. |
| **Pilot** | **Piloto** | A collaborator certified to pilot one or more aircraft models, responsible for creating and managing flight plans. Associated with a system user and an air transport company. | Colaborador certificado para pilotar um ou mais modelos de aeronave, responsável por criar e gerir planos de voo. Associado a um utilizador do sistema e a uma empresa de transporte aéreo. |
| **Pilot: certifications** | **Piloto: certificações** | The set of aircraft models the pilot is certified to fly. A pilot must have at least one certification. | Conjunto de modelos de aeronave que o piloto está certificado a pilotar. Um piloto deve ter pelo menos uma certificação. |
| **PilotStatus** | **Estado do Piloto** | Enumeration: `ACTIVE` (can be assigned to flights) or `INACTIVE` (cannot be assigned to new flight plans). | Enumeração: `ACTIVE` (pode ser atribuído a voos) ou `INACTIVE` (não pode ser atribuído a novos planos de voo). |
| **Flight Control Operator** | **Operador de Controlo de Voo** | A user responsible for monitoring and simulating flights. | Utilizador responsável por monitorizar e simular voos. |
| **Weather Person** | **Responsável Meteorológico** | A user responsible for providing weather data. | Utilizador responsável por fornecer dados meteorológicos. |
| **Security Clearance** | **Autorização de Segurança** | A value object held by every user, with an expiration date after which system access is revoked. | Objeto de valor de cada utilizador, com data de expiração após a qual o acesso ao sistema é revogado. |
| **Air Transport Company** | **Empresa de Transporte Aéreo** | An organization that owns aircraft, operates flight routes, and employs collaborators. Identified by unique IATA and ICAO codes. | Organização que possui aeronaves, opera rotas de voo e emprega colaboradores. Identificada por códigos IATA e ICAO únicos. |
| **Air Transport Company: companyName** | **Empresa de Transporte Aéreo: nome** | The legal name of the air transport company. | Nome legal da empresa de transporte aéreo. |
| **Air Transport Company: iataCode** | **Empresa de Transporte Aéreo: código IATA** | The 2-letter IATA code uniquely identifying the air transport company (e.g., `TP` for TAP Air Portugal). | Código IATA de 2 letras que identifica unicamente a empresa de transporte aéreo (ex.: `TP` para a TAP Air Portugal). |
| **Air Transport Company: icaoCode** | **Empresa de Transporte Aéreo: código ICAO** | The 2–3 letter ICAO code uniquely identifying the air transport company (e.g., `TAP` for TAP Air Portugal). | Código ICAO de 2-3 letras que identifica unicamente a empresa de transporte aéreo (ex.: `TAP` para a TAP Air Portugal). |
| **Airport** | **Aeroporto** | A location where flights depart and arrive, identified by unique IATA and ICAO codes, and positioned by coordinates. | Local onde os voos partem e chegam, identificado por códigos IATA e ICAO únicos, e posicionado por coordenadas. |
| **Airport: iataCode** | **Aeroporto: código IATA** | The 3-letter IATA code uniquely identifying the airport worldwide (e.g., `OPO` for Porto Airport). | Código IATA de 3 letras que identifica unicamente o aeroporto a nível mundial. |
| **Airport: icaoCode** | **Aeroporto: código ICAO** | The 4-letter ICAO code uniquely identifying the airport worldwide (e.g., `LPPR` for Porto Airport). | Código ICAO de 4 letras que identifica unicamente o aeroporto a nível mundial. |
| **Coordinates** | **Coordenadas** | A value object representing a geographic position defined by latitude, longitude, and altitude. | Objeto de valor que representa uma posição geográfica definida por latitude, longitude e altitude. |
| **Maker** | **Fabricante** | An entity that manufactures aircraft models and engine models. Only basic information (name, country) is stored in the system. | Entidade que fabrica modelos de aeronaves e motores. Apenas informação básica é armazenada no sistema. |
| **Aircraft Model** | **Modelo de Aeronave** | Defines the technical characteristics of an aircraft type, including weight limits, fuel capacity, aerodynamic coefficients, and maximum range. | Define as características técnicas de um tipo de aeronave, incluindo limites de peso, capacidade de combustível, coeficientes aerodinâmicos e alcance máximo. |
| **Aircraft Model: modelId** | **Modelo de Aeronave: identificador** | Value object representing the unique identifier of the aircraft model (e.g., `A320-200`). The combination of model name and maker must be unique in the system. | Objeto de valor que representa o identificador único do modelo de aeronave. A combinação de nome do modelo e fabricante deve ser única. |
| **Aircraft Type** | **Tipo de Aeronave** | Enumeration classifying an aircraft model by its operational purpose: `PASSENGER`, `CARGO`, or `MIXED`. | Enumeração que classifica um modelo de aeronave pela sua finalidade operacional. |
| **Aircraft Model: MTOW** | **Modelo de Aeronave: MTOW** | Maximum Take-Off Weight. The maximum allowable total weight of the aircraft at the moment of take-off (kg). | Peso Máximo de Descolagem. Peso total máximo permitido da aeronave no momento da descolagem (kg). |
| **Aircraft Model: MZFW** | **Modelo de Aeronave: MZFW** | Maximum Zero Fuel Weight. The maximum allowable weight of the aircraft excluding usable fuel (kg). | Peso Máximo sem Combustível. Peso máximo permitido da aeronave excluindo o combustível utilizável (kg). |
| **Aircraft Model: maxFuelCapacity** | **Modelo de Aeronave: capacidade máxima de combustível** | The maximum amount of fuel the aircraft can carry, expressed in litres or kg. | Quantidade máxima de combustível que a aeronave pode transportar. |
| **Aircraft Model: wingSpan** | **Modelo de Aeronave: envergadura** | The total tip-to-tip width of the aircraft's wings (m). Used to compute the aspect ratio. | Largura total asa a asa da aeronave (m). Utilizada para calcular o rácio de aspeto. |
| **Aircraft Model: wingArea** | **Modelo de Aeronave: área alar** | The total surface area of the aircraft's wings (m²). Value object {@link Area}. Used in lift and drag calculations. | Área total da superfície das asas da aeronave (m²). Usada nos cálculos de sustentação e arrasto. |
| **Aircraft Model: aspectRatio** | **Modelo de Aeronave: rácio de aspeto** | The ratio of the wing span squared to the wing area (AR = b²/A). Dimensionless parameter used in the induced drag coefficient formula. | Rácio do quadrado da envergadura pela área da asa. Parâmetro adimensional utilizado na fórmula do coeficiente de arrasto induzido. |
| **Aircraft Model: oswaldFactor** | **Modelo de Aeronave: fator de Oswald** | The Oswald efficiency factor (e), a dimensionless number between 0 and 1 representing the aerodynamic efficiency of the wing planform. | O fator de eficiência de Oswald (e), número adimensional entre 0 e 1 que representa a eficiência aerodinâmica da planta alar. |
| **Aircraft Model: dragCoefficient (Cd0)** | **Modelo de Aeronave: coeficiente de arrasto** | The zero-lift drag coefficient. Value object {@link Coefficient}. Baseline drag when lift is zero. | O coeficiente de arrasto a sustentação zero. Arrasto base quando a sustentação é zero. |
| **Aircraft Model: numberOfEngines** | **Modelo de Aeronave: número de motores** | The number of engines installed on the aircraft model. Used in total thrust and fuel consumption calculations. | Número de motores instalados no modelo de aeronave. |
| **Aircraft** | **Aeronave** | A physical aircraft identified by a unique registration number, associated with a model and owned by an air transport company. | Aeronave física identificada por um número de registo único, associada a um modelo e pertencente a uma empresa de transporte aéreo. |
| **Aircraft: registrationNumber** | **Aeronave: número de registo** | Value object ({@link RegistrationNumber}) — the unique worldwide identifier of a physical aircraft (e.g., `CS-TKK`). | Identificador único mundial de uma aeronave física. Não podem existir duas aeronaves com o mesmo número. |
| **Operational Status** | **Estado Operacional** | Enumeration defining the operational state of an aircraft: `ACTIVE` (available for operations) or `DECOMMISSIONED` (permanently retired from service). The former value `RETIRED` was renamed to `DECOMMISSIONED` per US071. | Enumeração que define o estado operacional de uma aeronave. |
| **Cabin Configuration** | **Configuração de Cabine** | A value object describing the seat distribution per class (first, business, economy) for a specific aircraft. | Objeto de valor que descreve a distribuição de lugares por classe para uma aeronave concreta. |
| **Engine Model** | **Modelo de Motor** | Entity representing a type of engine with specific performance characteristics. An aircraft model must have at least one certified engine model; the same engine model cannot be added twice. | Entidade que representa um tipo de motor com características de desempenho específicas. Um modelo de aeronave deve ter pelo menos um motor certificado. |
| **Engine Model: engineModelId** | **Modelo de Motor: identificador** | Value object ({@link EngineModelId}) uniquely identifying an engine model by its name and maker. | Objeto de valor que identifica unicamente um modelo de motor pelo seu nome e fabricante. |
| **Engine Type** | **Tipo de Motor** | Enumeration classifying an engine model by its propulsion principle: `TURBOPROP`, `TURBOFAN`, `TURBOJET`, `RAMJET`, or `ELECTRIC_PROPELLER`. | Enumeração que classifica um modelo de motor pelo seu princípio de propulsão. |
| **Engine Model: thrustAtStandstill** | **Modelo de Motor: impulso parado** | The engine's thrust output at standstill (sea level, zero speed). Value object {@link Thrust}. Maximum thrust the engine can produce. | Impulso do motor parado (nível do mar, velocidade zero). Impulso máximo que o motor pode produzir. |
| **Engine Model: thrustAtCruiseSpeed** | **Modelo de Motor: impulso em cruzeiro** | The engine's thrust output at cruise speed (sea level). Value object {@link Thrust}. Must be less than standstill thrust. | Impulso do motor à velocidade de cruzeiro (nível do mar). Deve ser inferior ao impulso parado. |
| **Engine Model: cruiseSpeedMach** | **Modelo de Motor: Mach de cruzeiro** | The Mach number at which the engine achieves its rated cruise thrust. Value object {@link Speed}. Together with thrust at standstill and cruise, allows linear interpolation of thrust at any speed. | Número de Mach a que o motor atinge o impulso de cruzeiro nominal. |
| **Engine Model: TSFC** | **Modelo de Motor: TSFC** | Thrust Specific Fuel Consumption. Measures the fuel efficiency of the engine relative to its thrust output (N/N/S). Used in fuel consumption calculations. | Consumo Específico de Combustível por Impulso. Mede a eficiência de combustível do motor relativamente ao impulso produzido. |
| **Engine Model: lapseRateFactor** | **Modelo de Motor: fator de decréscimo** | Value object {@link Coefficient} — the exponent in the altitude thrust-lapse equation T(h) = T₀ × (ρ(h)/ρ₀)^factor. Captures how rapidly engine thrust decreases with altitude. | Expoente na equação de decréscimo de impulso com a altitude. Captura a rapidez com que o impulso diminui com a altitude. |
| **Engine Model: fuelType** | **Modelo de Motor: tipo de combustível** | The type of fuel consumed by the engine, expressed as a {@link FuelType} enumeration value. Determines compatibility with airport fuelling infrastructure. | O tipo de combustível consumido pelo motor. Determina a compatibilidade com a infraestrutura de abastecimento nos aeroportos. |
| **Fuel Type** | **Tipo de Combustível** | Enumeration: `JET_A1` (most widely used jet fuel), `JET_A` (US-market variant), or `AVGAS` (aviation gasoline for piston engines). | Enumeração que classifica o combustível utilizado por um modelo de motor. |
| **Flight Route** | **Rota de Voo** | Entity connecting an origin airport to a destination airport, owned by an air transport company and identified by a {@link RouteDesignator}. Routes may be deactivated from a specific date onwards. | Entidade que liga um aeroporto de origem a um de destino, pertencente a uma empresa de transporte aéreo. Pode ser desativada a partir de uma data. |
| **Flight Route: designator** | **Rota de Voo: designador** | Value object ({@link RouteDesignator}) — the business identifier of the route. Format: 2 uppercase letters (company IATA code) followed by 1–4 digits (e.g., `TP123`). | Identificador de negócio da rota. Formato: 2 letras maiúsculas + 1-4 dígitos. |
| **Flight Route: active** | **Rota de Voo: ativo** | Boolean indicating whether the route is currently active. Inactive routes cannot have flights created on or after the deactivation date. | Booleano que indica se a rota está ativa. Rotas inativas não permite criar voos na data de desativação ou posterior. |
| **Flight Route: deactivatedFrom** | **Rota de Voo: desativada desde** | The date from which a flight route becomes unavailable. No new flight plans can be created on that route on or after the deactivation date. | Data a partir da qual uma rota de voo deixa de estar disponível. |
| **Flight** | **Voo** | A concrete instance of a flight route, identified by a designator, with a departure day and scheduled arrival time. | Instância concreta de uma rota de voo, identificada por um designador, com um dia de partida e hora de chegada prevista. |
| **Flight Type** | **Tipo de Voo** | Enumeration: `REGULAR` (operates on fixed weekdays) or `CHARTER` (operates on a specific date, typically under contract). | Enumeração que classifica um voo pela sua natureza operacional. |
| **Flight Plan** | **Plano de Voo** | Aggregate root defining how a flight is executed. Includes the assigned aircraft, pilot, fuel load, departure date/time, weather data, legs, and DSL content. | Agregado raiz que define como um voo é executado. Inclui aeronave, piloto, combustível, data/hora, dados meteorológicos, trechos e conteúdo DSL. |
| **Flight Plan: flightPlanId** | **Plano de Voo: identificador** | Value object ({@link FlightPlanId}) — the unique identity of a flight plan. | Objeto de valor que identifica unicamente um plano de voo. |
| **Flight Plan: status** | **Plano de Voo: estado** | The lifecycle state of the flight plan. See {@link FlightPlanStatus}. | Estado do ciclo de vida do plano de voo. |
| **Flight Plan: totalDistance** | **Plano de Voo: distância total** | The total distance of the flight plan across all legs (km). Served from DSL data after import. | Distância total do plano de voo em todos os trechos (km). |
| **Flight Plan: estimatedFuel** | **Plano de Voo: combustível estimado** | The estimated total fuel for the flight plan (kg). Served from DSL data after import. | Combustível total estimado para o plano de voo (kg). |
| **Flight Plan: departureDateTime** | **Plano de Voo: data/hora de partida** | The scheduled departure date and time for the flight. | Data e hora prevista de partida do voo. |
| **Flight Plan: dslContent** | **Plano de Voo: conteúdo DSL** | The DSL source text associated with this flight plan. Stored at creation or import time. Used by US085 for validation and physical testing without requiring an external file. | Texto fonte DSL associado a este plano de voo. Armazenado na criação ou importação. |
| **Flight Plan Status** | **Estado do Plano de Voo** | Enumeration defining the lifecycle state: `DRAFT`, `VALIDATED`, `FAILED`, `APPROVED`, `ACTIVE`, `COMPLETED`, or `CANCELLED`. Adding weather data to a previously validated/approved plan returns it to `DRAFT`. | Enumeração que define o estado do ciclo de vida. Adicionar dados meteorológicos retorna a `DRAFT`. |
| **Flight Designator** | **Designador de Voo** | A value object uniquely identifying a flight, composed of the airline code, flight number, and optional operational suffix. Format: `xxn(n)(n)(n)(a)`. | Objeto de valor que identifica unicamente um voo. |
| **Flight Leg** | **Trecho de Voo** | Entity representing a single non-stop journey between two airports within a flight plan. Contains its own departure, arrival, fuel load, and set of flight segments. | Entidade que representa uma viagem direta entre dois aeroportos dentro de um plano de voo. Contém partida, chegada, combustível e segmentos. |
| **Flight Leg: fuel** | **Trecho de Voo: combustível** | The fuel allocated specifically for this leg (kg). Must be strictly positive. | Combustível atribuído especificamente a este trecho (kg). |
| **Flight Segment** | **Segmento de Voo** | Value object representing a linear path within a flight leg. Characterized by flight mode (climb, cruise, or descend), start/end waypoints, altitude slot, corridor width, and wind conditions. | Objeto de valor que representa um caminho linear dentro de um trecho de voo. |
| **Flight Segment: mode** | **Segmento de Voo: modo** | The flight mode for this segment: `climb`, `cruise`, or `descend`. | O modo de voo para este segmento. |
| **Flight Segment: minAltitude** | **Segmento de Voo: altitude mínima** | The lower bound of the allowed altitude slot for this segment (m). | Limite inferior do slot de altitude permitido (m). |
| **Flight Segment: maxAltitude** | **Segmento de Voo: altitude máxima** | The upper bound of the allowed altitude slot for this segment (m). | Limite superior do slot de altitude permitido (m). |
| **Flight Segment: width** | **Segmento de Voo: largura** | The lateral width of the airspace corridor assigned to this segment (m). Used for collision detection and separation assurance. | Largura lateral do corredor de espaço aéreo atribuído (m). |
| **Flight Segment: windDirection** | **Segmento de Voo: direção do vento** | The wind direction at this segment, expressed as an angle in degrees relative to True North (0–360°). | Direção do vento em graus relativamente ao Norte Verdadeiro. |
| **Flight Segment: windSpeed** | **Segmento de Voo: velocidade do vento** | The wind speed at this segment, expressed in m/s. Used to compute effective ground speed and fuel consumption during simulation. | Velocidade do vento em m/s. |
| **Waypoint** | **Ponto de Passagem** | Value object representing a geographic position with latitude, longitude, and altitude. Used as start/end points of flight segments. | Objeto de valor que representa uma posição geográfica com latitude, longitude e altitude. Usado como pontos início/fim dos segmentos. |
| **Flight Plan DSL** | **DSL de Plano de Voo** | The Domain-Specific Language used to describe flight plans. Supports flight type (regular/charter), multi-leg structures, segments with coordinates/altitude/wind, and fuel per leg. Processed via ANTLR4. | Linguagem de domínio específico usada para descrever planos de voo. Processada via ANTLR4. |
| **File Format Type** | **Tipo de Formato de Ficheiro** | Enumeration: `FLIGHT_DSL` (valid DSL file), `UNKNOWN` (unrecognized extension), or `INVALID` (empty, corrupted, or BOM-marked). | Enumeração para classificar ficheiros de entrada antes do processamento ANTLR. |
| **File Format Validator** | **Validador de Formato de Ficheiro** | Domain service that performs pre-ANTLR validation: checks file existence, extension, emptiness, and BOM markers. Returns a {@link FormatValidationResult}. | Serviço de domínio que efetua validação pré-ANTLR: verifica existência, extensão, ficheiro vazio e marcadores BOM. |
| **Format Validation Result** | **Resultado de Validação de Formato** | Value object containing the outcome of file format validation: validity flag, {@link FileFormatType}, and list of error messages. | Objeto de valor com o resultado da validação de formato: flag de validade, tipo de formato e lista de erros. |
| **Flight Plan Weather Data** | **Dados meteorológicos do plano de voo** | Association between a flight plan and one or more weather data records. Adding or changing weather data invalidates previous validation. | Associação entre um plano de voo e registos meteorológicos. Alterações invalidam validação anterior. |

## Air Control & Weather

| **Term (EN)** | **Termo (PT)** | **Description (EN)** | **Descrição (PT)** |
|:---|:---|:---|:---|
| **Air Control Area** | **Área de Controlo Aéreo** | Aggregate root representing a geographical region responsible for managing air traffic, bounded by a geographical boundary and containing one or more airports. | Agregado raiz que representa uma região geográfica responsável pela gestão do tráfego aéreo. |
| **Air Control Area: areaCode** | **Área de Controlo Aéreo: código** | The unique code identifying the air control area within the system. | Código único que identifica a área de controlo aéreo. |
| **Air Control Area: minimumFuelRequired** | **Área de Controlo Aéreo: combustível mínimo** | The minimum amount of fuel an aircraft must have on board upon landing at any airport within this area. | Combustível mínimo que uma aeronave deve ter a bordo para aterrar em aeroportos desta área. |
| **Geo Boundary** | **Fronteira Geográfica** | Value object defining the rectangular geographical boundary of an air control area via its four cardinal extremes (north, south, east, west). | Objeto de valor que define a fronteira geográfica retangular de uma área de controlo aéreo. |
| **Weather Data** | **Dados Meteorológicos** | Aggregate root representing weather conditions for a specific air control area and time period. Stores temperature, wind speed, wind direction, humidity, and pressure. | Agregado raiz que representa condições meteorológicas para uma área de controlo aéreo e período temporal específicos. |
| **Weather Bulk Import** | **Importação Massiva Meteorológica** | Process of importing several weather data records from an external file. Supports CSV; extensible through importer implementations. | Processo de importar vários registos meteorológicos de um ficheiro externo. Suporta CSV e é extensível. |
| **Weather Source / Provider** | **Fonte / Fornecedor Meteorológico** | External weather service provider or file format from which weather records originate. Importers translate provider data into {@link WeatherData}. | Serviço meteorológico externo ou formato de ficheiro de onde os registos tiveram origem. |
| **Weather Consultation** | **Consulta Meteorológica** | Operation that retrieves weather data for a selected air control area and day. Available to Weather Persons, Pilots, Flight Control Operators, and Admins. | Operação que consulta dados meteorológicos para uma área e dia selecionados. |
| **Weather Time Period** | **Período Meteorológico** | Value object ({@link TimePeriod}) defining the start and end date/time during which a weather record is valid. The end must be after the start. | Objeto de valor que define o início e fim do período em que um registo é válido. |
| **Temperature** | **Temperatura** | Value object representing air temperature within physically plausible bounds accepted by the domain. | Objeto de valor que representa a temperatura do ar dentro dos limites fisicamente plausíveis. |
| **Wind Speed** | **Velocidade do Vento** | Value object representing wind speed in metres per second. Cannot be negative. | Objeto de valor que representa a velocidade do vento em metros por segundo. |
| **Wind Direction** | **Direção do Vento** | Value object representing wind direction in degrees within the accepted compass range. | Objeto de valor que representa a direção do vento em graus. |
| **Humidity** | **Humidade** | Value object representing relative humidity as a percentage. | Objeto de valor que representa a humidade relativa em percentagem. |
| **Pressure** | **Pressão Atmosférica** | Value object representing atmospheric pressure in hPa. | Objeto de valor que representa a pressão atmosférica em hPa. |

## Simulation & Reporting

| **Term (EN)** | **Termo (PT)** | **Description (EN)** | **Descrição (PT)** |
|:---|:---|:---|:---|
| **Simulation Time Step** | **Passo Temporal da Simulação** | Discrete instant in the SCOMP simulation. All active flight processes and the parent safety detection thread must complete the current step before the simulation advances. | Instante discreto da simulação SCOMP. Todos os processos devem terminar o passo antes de avançar. |
