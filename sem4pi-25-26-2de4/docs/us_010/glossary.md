# Glossary – Domain Model (AISafe)

**This glossary defines the key domain concepts used in the AISafe system, ensuring a consistent ubiquitous language across the project.**


| **Term (EN)**                             | **Termo (PT)**                        | **Description (EN)**                                                                                                                                      | **Descrição (PT)**                                                                                                                                                       |
|:------------------------------------------| :------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **User**                                  | **Utilizador**                        | Represents a system user uniquely identified by email, with authentication and authorization capabilities.                                                 | Representa um utilizador do sistema identificado unicamente pelo email, com capacidades de autenticação e autorização.                                                   |
| **User: status**                          | **Utilizador: estado**                | Indicates whether the user account is active or inactive. Inactive users cannot access the system.                                                        | Indica se a conta do utilizador está ativa ou inativa. Utilizadores inativos não podem aceder ao sistema.                                                                |
| **User: skillsAssessmentDate**            | **Utilizador: data de avaliação de competências** | The date of the user's last skills assessment. Must be renewed every 5 years as required by regulation.                                      | Data da última avaliação de competências do utilizador. Deve ser renovada a cada 5 anos conforme exigido pela regulamentação.                                            |
| **Role**                                  | **Papel**                             | A value object defining the permissions and responsibilities assigned to a user. A user may hold one or more roles.                                        | Objeto de valor que define as permissões e responsabilidades atribuídas a um utilizador. Um utilizador pode ter um ou mais papéis.                                       |
| **Role Type**                           | **Tipo de Papel**                   | Enumeration of all possible roles in the system: `ADMIN`, `BACKOFFICE_OPERATOR`, `COLLABORATOR`, `AIR_TRANSPORT_COMPANY_COLLABORATOR`, `PILOT`, `FLIGHT_CONTROL_OPERATOR`, `WEATHER_PERSON`. The `ATCC` role was removed; `COLLABORATOR` and `AIR_TRANSPORT_COMPANY_COLLABORATOR` were added to distinguish generic collaborators from those tied to a specific air transport company. | Enumeração de todos os papéis possíveis no sistema: `ADMIN`, `BACKOFFICE_OPERATOR`, `COLLABORATOR`, `AIR_TRANSPORT_COMPANY_COLLABORATOR`, `PILOT`, `FLIGHT_CONTROL_OPERATOR`, `WEATHER_PERSON`. O papel `ATCC` foi removido; foram adicionados `COLLABORATOR` e `AIR_TRANSPORT_COMPANY_COLLABORATOR` para distinguir colaboradores genéricos dos associados a uma empresa de transporte aéreo. |
| **Admin**                                 | **Administrador**                     | A user responsible for managing users and system configuration.                                                                                           | Utilizador responsável pela gestão de utilizadores e configuração do sistema.                                                                                            |
| **Backoffice Operator**                   | **Operador de Backoffice**            | A user responsible for configuring core domain data such as companies, airports, and aircraft models.                                                     | Utilizador responsável pela configuração dos dados principais do domínio como empresas, aeroportos e modelos de aeronaves.                                               |
| **Pilot**                                 | **Piloto**                            | A collaborator certified to pilot one or more aircraft models, responsible for creating and managing flight plans.                                         | Colaborador certificado para pilotar um ou mais modelos de aeronave, responsável por criar e gerir planos de voo.                                                        |
| **Flight Control Operator**               | **Operador de Controlo de Voo**       | A user responsible for monitoring and simulating flights.                                                                                                 | Utilizador responsável por monitorizar e simular voos.                                                                                                                   |
| **Weather Person**                        | **Responsável Meteorológico**         | A user responsible for providing weather data.                                                                                                            | Utilizador responsável por fornecer dados meteorológicos.                                                                                                                |
| **Security Clearance**                    | **Autorização de Segurança**          | A value object held by every user, with an expiration date after which system access is revoked.                                                          | Objeto de valor de cada utilizador, com data de expiração após a qual o acesso ao sistema é revogado.                                                                    |
| **Security Clearance: expirationDate**    | **Autorização de Segurança: data de expiração** | The date on which the security clearance automatically expires. The user loses system access until the clearance is renewed.          | Data em que a autorização de segurança expira automaticamente. O utilizador perde o acesso ao sistema até a autorização ser renovada.                                    |
| **Air Transport Company**                 | **Empresa de Transporte Aéreo**       | An organization that owns aircraft, operates flight routes, and employs collaborators. Identified by unique IATA and ICAO codes.                           | Organização que possui aeronaves, opera rotas de voo e emprega colaboradores. Identificada por códigos IATA e ICAO únicos.                                               |
| **Air Transport Company: iataCode**       | **Empresa de Transporte Aéreo: código IATA** | The 2-letter IATA code uniquely identifying the air transport company (e.g., `TP` for TAP Air Portugal).                              | Código IATA de 2 letras que identifica unicamente a empresa de transporte aéreo (ex.: `TP` para a TAP Air Portugal).                                                     |
| **Air Transport Company: icaoCode**       | **Empresa de Transporte Aéreo: código ICAO** | The 2–3 letter ICAO code uniquely identifying the air transport company (e.g., `TAP` for TAP Air Portugal).                           | Código ICAO de 2-3 letras que identifica unicamente a empresa de transporte aéreo (ex.: `TAP` para a TAP Air Portugal).                                                  |
| **Collaborator**                          | **Colaborador**                       | A person employed by an air transport company or assigned to an air control area, associated with a system user account. A customer may be an air transport company or an air control area. | Pessoa empregada por uma empresa de transporte aéreo ou afeta a uma área de controlo aéreo, associada a uma conta de utilizador do sistema. Um cliente pode ser uma empresa de transporte aéreo ou uma área de controlo aéreo. |
| **Collaborator: position**                | **Colaborador: cargo**                | The collaborator's job title or role within their employing organization (e.g., dispatcher, captain, first officer).                                       | Cargo ou função do colaborador na organização empregadora (ex.: despachante, comandante, co-piloto).                                                                     |
| **Aircraft**                              | **Aeronave**                          | A physical aircraft identified by a unique registration number, associated with a model and owned by an air transport company.                             | Aeronave física identificada por um número de registo único, associada a um modelo e pertencente a uma empresa de transporte aéreo.                                      |
| **Aircraft: registrationNumber**          | **Aeronave: número de registo**   | The unique worldwide identifier of a physical aircraft (e.g., `CS-TKK`). No two aircraft may share the same registration number.                          | Identificador único mundial de uma aeronave física (ex.: `CS-TKK`). Não podem existir duas aeronaves com o mesmo número de registo.                                      |
| **Operational Status**                    | **Estado Operacional**              | Enumeration defining the operational state of an aircraft: `ACTIVE` (available for operations) or `DECOMMISSIONED` (permanently retired from service). The former value `RETIRED` was renamed to `DECOMMISSIONED` to better reflect the domain language used in US071. | Enumeração que define o estado operacional de uma aeronave: `ACTIVE` (disponível para operações) ou `DECOMMISSIONED` (retirada permanentemente de serviço). O valor anterior `RETIRED` foi renomeado para `DECOMMISSIONED` para melhor refletir a linguagem do domínio usada no US071. |
| **Aircraft Model**                        | **Modelo de Aeronave**                | Defines the technical characteristics of an aircraft type, including weight limits, fuel capacity, aerodynamic coefficients, and maximum range.            | Define as características técnicas de um tipo de aeronave, incluindo limites de peso, capacidade de combustível, coeficientes aerodinâmicos e alcance máximo.            |
| **Aircraft Model: modelId**               | **Modelo de Aeronave: identificador do modelo** | The unique identifier of the aircraft model (e.g., `A320-200`). The combination of model name and maker must be unique in the system.   | Identificador único do modelo de aeronave (ex.: `A320-200`). A combinação de nome do modelo e fabricante deve ser única no sistema.                                      |
| **Aircraft Model: MTOW**                  | **Modelo de Aeronave: MTOW**          | Maximum Take-Off Weight. The maximum allowable total weight of the aircraft at the moment of take-off (kg).                                                | Peso Máximo de Descolagem. Peso total máximo permitido da aeronave no momento da descolagem (kg).                                                                        |
| **Aircraft Model: MZFW**                  | **Modelo de Aeronave: MZFW**          | Maximum Zero Fuel Weight. The maximum allowable weight of the aircraft excluding usable fuel (kg).                                                         | Peso Máximo sem Combustível. Peso máximo permitido da aeronave excluindo o combustível utilizável (kg).                                                                  |
| **Aircraft Model: maxFuelCapacity**       | **Modelo de Aeronave: capacidade máxima de combustível** | The maximum amount of fuel the aircraft can carry, expressed in litres or kg.                                           | Quantidade máxima de combustível que a aeronave pode transportar, expressa em litros ou kg.                                                                              |
| **Aircraft Model: maxPassengerCapacity**  | **Modelo de Aeronave: capacidade máxima de passageiros** | The maximum number of passengers the aircraft model can accommodate across all cabin classes.                       | Número máximo de passageiros que o modelo de aeronave pode acomodar em todas as classes de cabine.                                                                       |
| **Aircraft Model: maxRange**              | **Modelo de Aeronave: alcance máximo** | The maximum distance the aircraft model can fly without refuelling, under standard conditions (km).                                                   | Distância máxima que o modelo de aeronave consegue percorrer sem reabastecimento, em condições standard (km).                                                            |
| **Aircraft Model: wingSpan**              | **Modelo de Aeronave: envergadura**  | The total tip-to-tip width of the aircraft's wings (m). Used together with wing area to compute the aspect ratio for aerodynamic calculations. | Largura total asa a asa da aeronave (m). Utilizada em conjunto com a área da asa para calcular o rácio de aspeto nos cálculos aerodinâmicos. |
| **Aircraft Model: aspectRatio**           | **Modelo de Aeronave: rácio de aspeto**  | The ratio of the wing span squared to the wing area (AR = b²/A). A dimensionless parameter used in the induced drag coefficient formula. | Rácio do quadrado da envergadura pela área da asa (AR = b²/A). Parâmetro adimensional utilizado na fórmula do coeficiente de arrasto induzido. |
| **Aircraft Model: oswaldFactor**          | **Modelo de Aeronave: fator de Oswald**  | The Oswald efficiency factor (e), a dimensionless number between 0 and 1 representing the aerodynamic efficiency of the wing planform. Used in the drag polar equation: C_D = C_D0 + C_L²/(π·AR·e). | O fator de eficiência de Oswald (e), número adimensional entre 0 e 1 que representa a eficiência aerodinâmica da planta alar. Usado na equação polar de arrasto: C_D = C_D0 + C_L²/(π·AR·e). |
| **Aircraft Model: numberOfEngines**       | **Modelo de Aeronave: número de motores**  | The number of engines installed on the aircraft model. Used in total thrust and fuel consumption calculations. | Número de motores instalados no modelo de aeronave. Usado nos cálculos de impulso total e consumo de combustível. |
| **Aircraft Type**                         | **Tipo de Aeronave**                  | Enumeration classifying an aircraft model by its operational purpose: `PASSENGER`, `CARGO`, or `MIXED`.                                                   | Enumeração que classifica um modelo de aeronave pela sua finalidade operacional: `PASSENGER`, `CARGO` ou `MIXED`.                                                        |
| **Engine Model**                          | **Modelo de Motor**                   | Represents a type of engine with specific performance characteristics such as thrust and fuel consumption. An aircraft model must have at least one certified engine model; the same engine model cannot be added twice. | Representa um tipo de motor com características de desempenho específicas, como impulso e consumo de combustível. Um modelo de aeronave deve ter pelo menos um motor certificado; o mesmo modelo de motor não pode ser adicionado duas vezes. |
| **Engine Model: TSFC**                    | **Modelo de Motor: TSFC**             | Thrust Specific Fuel Consumption. Measures the fuel efficiency of the engine relative to its thrust output (N/N/S). Used in fuel consumption calculations. | Consumo Específico de Combustível por Impulso. Mede a eficiência de combustível do motor relativamente ao impulso produzido (N/N/S). Usado nos cálculos de consumo.      |
| **Engine Model: lapseRateFactor**         | **Modelo de Motor: fator de decréscimo de impulso**  | A coefficient (exponent) used in the altitude thrust-lapse equation T_altitude = T_sea_level · (ρ/ρ₀)^lapseRateFactor. Captures how rapidly engine thrust decreases with altitude. | Coeficiente (expoente) usado na equação de decréscimo de impulso com a altitude T_altitude = T_sea_level · (ρ/ρ₀)^lapseRateFactor. Captura a rapidez com que o impulso diminui com a altitude. |
| **Engine Model: cruiseSpeedMach**         | **Modelo de Motor: velocidade de cruzeiro Mach**  | The Mach number at which the engine achieves its rated cruise thrust. Together with thrust at standstill and cruise speed, it allows linear interpolation of thrust at any speed. | Número de Mach a que o motor atinge o impulso de cruzeiro nominal. Em conjunto com o impulso parado e em cruzeiro, permite interpolação linear do impulso a qualquer velocidade. |
| **Engine Model: fuelType**                | **Modelo de Motor: tipo de combustível**  | The type of fuel consumed by the engine, expressed as a `FuelType` enumeration value. Determines compatibility with airport fuelling infrastructure. | O tipo de combustível consumido pelo motor, expresso como valor da enumeração `FuelType`. Determina a compatibilidade com a infraestrutura de abastecimento nos aeroportos. |
| **Fuel Type**                             | **Tipo de Combustível**             | Enumeration classifying the fuel used by an engine model: `JET_A1` (the most widely used jet fuel worldwide), `JET_A` (US-market variant), or `AVGAS` (aviation gasoline, for piston engines). | Enumeração que classifica o combustível utilizado por um modelo de motor: `JET_A1` (o mais utilizado mundialmente), `JET_A` (variante do mercado norte-americano) ou `AVGAS` (gasolina de aviação, para motores a pistão). |
| **Engine Type**                           | **Tipo de Motor**                     | Enumeration classifying an engine model by its propulsion principle: `TURBOPROP`, `TURBOFAN`, `TURBOJET`, `RAMJET`, or `ELECTRIC_PROPELLER`.              | Enumeração que classifica um modelo de motor pelo seu princípio de propulsão: `TURBOPROP`, `TURBOFAN`, `TURBOJET`, `RAMJET` ou `ELECTRIC_PROPELLER`.                    |
| **Maker**                                 | **Fabricante**                        | An entity that manufactures aircraft models and engine models. Only basic information is stored in the system.                                             | Entidade que fabrica modelos de aeronaves e motores. Apenas informação básica é armazenada no sistema.                                                                   |
| **Air Control Area**                      | **Área de Controlo Aéreo**            | A geographical region responsible for managing air traffic, bounded by a geographical boundary and containing one or more airports.                       | Região geográfica responsável pela gestão do tráfego aéreo, delimitada por uma fronteira geográfica e contendo um ou mais aeroportos.                                    |
| **Air Control Area: areaCode**            | **Área de Controlo Aéreo: código da área** | The unique code identifying the air control area within the system.                                                                              | Código único que identifica a área de controlo aéreo no sistema.                                                                                                         |
| **Air Control Area: minimumFuelRequired** | **Área de Controlo Aéreo: combustível mínimo exigido** | The minimum amount of fuel an aircraft must have on board upon landing at any airport within this area.                   | Quantidade mínima de combustível que uma aeronave deve ter a bordo no momento de aterrar em qualquer aeroporto desta área.                                                |
| **Geo Boundary**                          | **Fronteira Geográfica**              | A value object defining the rectangular geographical boundary of an air control area via its four cardinal extremes (north, south, east, west).            | Objeto de valor que define a fronteira geográfica retangular de uma área de controlo aéreo através dos seus quatro extremos cardinais (norte, sul, este, oeste).          |
| **Airport**                               | **Aeroporto**                         | A location where flights depart and arrive, identified by unique IATA and ICAO codes, and positioned by coordinates.                                      | Local onde os voos partem e chegam, identificado por códigos IATA e ICAO únicos, e posicionado por coordenadas.                                                          |
| **Airport: iataCode**                     | **Aeroporto: código IATA**            | The 3-letter IATA code uniquely identifying the airport worldwide (e.g., `OPO` for Porto Airport).                                                        | Código IATA de 3 letras que identifica unicamente o aeroporto a nível mundial (ex.: `OPO` para o Aeroporto do Porto).                                                    |
| **Airport: icaoCode**                     | **Aeroporto: código ICAO**            | The 4-letter ICAO code uniquely identifying the airport worldwide (e.g., `LPPR` for Porto Airport).                                                       | Código ICAO de 4 letras que identifica unicamente o aeroporto a nível mundial (ex.: `LPPR` para o Aeroporto do Porto).                                                   |
| **Flight**                                | **Voo**                               | A concrete instance of a flight route, identified by a designator, with a departure day and scheduled arrival time.                                       | Instância concreta de uma rota de voo, identificada por um designador, com um dia de partida e hora de chegada prevista.                                                 |
| **Flight Type**                           | **Tipo de Voo**                       | Enumeration classifying a flight by its operational nature: `REGULAR` (operates on fixed weekdays on a schedule) or `CHARTER` (operates on a specific date and time, typically under contract). | Enumeração que classifica um voo pela sua natureza operacional: `REGULAR` (opera em dias fixos da semana com horário programado) ou `CHARTER` (opera numa data e hora concretas, normalmente sob contrato). |
| **Flight Plan**                           | **Plano de Voo**                      | The root aggregate defining how a flight is executed, including the assigned aircraft, pilot, fuel load, passenger count, and cargo weight. Must be described using the Flight DSL and imported into the system for validation. | Agregado raiz que define como um voo é executado, incluindo aeronave, piloto, carga de combustível, número de passageiros e peso de carga. Deve ser descrito usando a DSL de voo e importado para o sistema para validação. |
| **Flight Plan: totalFuelLoad**            | **Plano de Voo: carga total de combustível** | The total amount of fuel loaded onto the aircraft at the start of the flight, expressed in kg or litres.                                        | Quantidade total de combustível carregada na aeronave no início do voo, expressa em kg ou litros.                                                                        |
| **Flight Route Status**                   | **Estado da Rota de Voo**             | Enumeration defining the operational state of a flight route: `ACTIVE` (open for new flights) or `INACTIVE` (deactivated, no new flights allowed).        | Enumeração que define o estado operacional de uma rota de voo: `ACTIVE` (aberta a novos voos) ou `INACTIVE` (desativada, não permite novos voos).                        |
| **Flight Designator**                     | **Designador de Voo**                 | A value object uniquely identifying a flight, composed of the airline code, flight number, and an optional operational suffix.                             | Objeto de valor que identifica unicamente um voo, composto pelo código da companhia, número de voo e sufixo operacional opcional.                                        |
| **Flight Designator: designator**         | **Designador de Voo: designador** | The full flight designator string in the format `xxn(n)(n)(n)(a)` (e.g., `TP123` or `TP123A`).                                                      | A string completa do designador de voo no formato `xxn(n)(n)(n)(a)` (ex.: `TP123` ou `TP123A`).                                                                         |
| **Flight Leg**                            | **Trecho de Voo**                   | A single non-stop journey between two airports, part of a flight plan. Each leg defines its own departure and arrival airports, fuel load, and a set of flight segments. A flight plan may have one or more legs. | Viagem direta entre dois aeroportos, parte de um plano de voo. Cada trecho define os seus aeroportos de partida e chegada, carga de combustível e conjunto de segmentos de voo. Um plano de voo pode ter um ou mais trechos. |
| **Flight Segment**                        | **Segmento de Voo**                 | A value object representing a linear path within a flight leg, connecting two geographic coordinates. Characterised by flight mode (climb, cruise, or descend), start and end coordinates, allowed altitude slots (`minAltitude`, `maxAltitude`), corridor width, and wind conditions (direction and speed). | Objeto de valor que representa um caminho linear dentro de um trecho de voo, ligando duas coordenadas geográficas. Caracterizado pelo modo de voo (subida, cruzeiro ou descida), coordenadas de início e fim, slots de altitude permitidos (`minAltitude`, `maxAltitude`), largura do corredor e condições de vento (direção e velocidade). |
| **Flight Segment: minAltitude**           | **Segmento de Voo: altitude mínima**  | The lower bound of the allowed altitude slot for this segment (m). The aircraft must remain above this altitude throughout the segment. | Limite inferior do slot de altitude permitido para este segmento (m). A aeronave deve permanecer acima desta altitude ao longo do segmento. |
| **Flight Segment: maxAltitude**           | **Segmento de Voo: altitude máxima**  | The upper bound of the allowed altitude slot for this segment (m). The aircraft must remain below this altitude throughout the segment. | Limite superior do slot de altitude permitido para este segmento (m). A aeronave deve permanecer abaixo desta altitude ao longo do segmento. |
| **Flight Segment: width**                 | **Segmento de Voo: largura**        | The lateral width of the airspace corridor assigned to this segment (m). Used for collision detection and separation assurance between flights. | A largura lateral do corredor de espaço aéreo atribuído a este segmento (m). Usada para deteção de colisões e garantia de separação entre voos. |
| **Flight Segment: windDirection**         | **Segmento de Voo: direção do vento**  | The wind direction at this segment, expressed as an angle in degrees relative to True North (0–360°). | A direção do vento neste segmento, expressa como ângulo em graus relativamente ao Norte Verdadeiro (0–360°). |
| **Flight Segment: windSpeed**             | **Segmento de Voo: velocidade do vento**  | The wind speed at this segment, expressed in m/s. Used to compute the effective ground speed and fuel consumption during simulation. | A velocidade do vento neste segmento, expressa em m/s. Usada para calcular a velocidade em relação ao solo e o consumo de combustível durante a simulação. |
| **Coordinates**                           | **Coordenadas**                       | A value object representing a geographic position defined by latitude, longitude, and altitude.                                                            | Objeto de valor que representa uma posição geográfica definida por latitude, longitude e altitude.                                                                        |
| **Cabin Configuration**                   | **Configuração de Cabine**            | A value object describing the seat distribution per class (first, business, economy) for a specific aircraft.                                             | Objeto de valor que descreve a distribuição de lugares por classe (primeira, negócios, económica) para uma aeronave concreta.                                            |
| **Flight Plan Status** | **Estado do Plano de Voo** | Enumeration defining the lifecycle state of a flight plan: `DRAFT`, `VALIDATED`, `FAILED`, `APPROVED`, `ACTIVE`, `COMPLETED`, or `CANCELLED`. Adding weather data to a previously validated or approved plan returns it to `DRAFT`. | Enumeracao que define o estado do ciclo de vida de um plano de voo: `DRAFT`, `VALIDATED`, `FAILED`, `APPROVED`, `ACTIVE`, `COMPLETED` ou `CANCELLED`. Ao adicionar dados meteorologicos a um plano previamente validado ou aprovado, o estado volta a `DRAFT`. |
| **Flight Route: deactivatedFrom** | **Rota de Voo: desativada desde** | The date from which a flight route becomes unavailable. No new flight plans can be created on that route on the deactivation date or later dates. | Data a partir da qual uma rota de voo deixa de estar disponivel. Nao podem ser criados novos planos de voo nessa rota na data de desativacao ou em datas posteriores. |
| **Weather Data** | **Dados Meteorologicos** | Aggregate root representing weather conditions for a specific air control area and time period. It stores temperature, wind speed, wind direction, humidity and pressure. | Agregado raiz que representa condicoes meteorologicas para uma area de controlo aereo e periodo temporal especificos. Guarda temperatura, velocidade do vento, direcao do vento, humidade e pressao. |
| **Weather Bulk Import** | **Importacao massiva meteorologica** | Process of importing several weather data records from an external file. The current implementation supports CSV and is extensible through importer implementations for different provider formats. | Processo de importar varios registos meteorologicos a partir de um ficheiro externo. A implementacao atual suporta CSV e e extensivel atraves de importadores para diferentes formatos de fornecedores. |
| **Weather Source / Provider** | **Fonte / fornecedor meteorologico** | External weather service provider or file format from which weather records originate. Importers translate provider data into the internal `WeatherData` model. | Servico meteorologico externo ou formato de ficheiro de onde os registos meteorologicos tiveram origem. Os importadores convertem esses dados para o modelo interno `WeatherData`. |
| **Weather Consultation** | **Consulta meteorologica** | Operation that retrieves weather data for a selected air control area and day. It is available to Weather Persons, Pilots, Flight Control Operators and Admins. | Operacao que consulta dados meteorologicos para uma area de controlo aereo e dia selecionados. Esta disponivel para responsaveis meteorologicos, pilotos, operadores de controlo de voo e administradores. |
| **Weather Time Period** | **Periodo meteorologico** | Value object defining the start and end date/time during which a weather record is valid. The end must be after the start. | Objeto de valor que define o inicio e o fim do periodo em que um registo meteorologico e valido. O fim deve ser posterior ao inicio. |
| **Temperature** | **Temperatura** | Weather value object representing air temperature within physically plausible bounds accepted by the domain. | Objeto de valor meteorologico que representa a temperatura do ar dentro dos limites fisicamente plausiveis aceites pelo dominio. |
| **Wind Speed** | **Velocidade do vento** | Weather value object representing wind speed in metres per second. It cannot be negative. | Objeto de valor meteorologico que representa a velocidade do vento em metros por segundo. Nao pode ser negativa. |
| **Wind Direction** | **Direcao do vento** | Weather value object representing wind direction in degrees within the accepted compass range. | Objeto de valor meteorologico que representa a direcao do vento em graus dentro do intervalo aceite da rosa dos ventos. |
| **Humidity** | **Humidade** | Weather value object representing relative humidity as a percentage. | Objeto de valor meteorologico que representa a humidade relativa em percentagem. |
| **Pressure** | **Pressao atmosferica** | Weather value object representing atmospheric pressure in hPa. | Objeto de valor meteorologico que representa a pressao atmosferica em hPa. |
| **Flight Plan Weather Data** | **Dados meteorologicos do plano de voo** | Association between a flight plan and one or more weather data records. Adding or changing weather data invalidates previous validation because the flight plan conditions changed. | Associacao entre um plano de voo e um ou mais registos meteorologicos. Adicionar ou alterar dados meteorologicos invalida a validacao anterior porque as condicoes do plano de voo mudaram. |
| **Simulation Time Step** | **Passo temporal da simulacao** | Discrete instant in the SCOMP simulation. All active flight processes and the parent safety detection thread must complete the current step before the simulation advances. | Instante discreto da simulacao SCOMP. Todos os processos de voo ativos e a thread de detecao de seguranca do processo pai devem terminar o passo atual antes de a simulacao avancar. |
